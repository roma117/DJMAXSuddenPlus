# DJMAX Sudden+

DJMAX RESPECT V の画面上部にレーンカバーを重ねる Windows 用ツールです。カバーの高さとゲーム内のハイスピードから、IIDX の緑数字に相当する表示時間を推定します。ゲーム本体のメモリや描画処理は変更しません。

## 起動

`DjmaxSuddenPlus-1.1.0.exe` を実行してください。初回は設定画面とカバーが表示されます。ゲームは「仮想フルスクリーン」または「ボーダーレスウィンドウ」に設定してください。真の排他フルスクリーンでは、Windows の通常の最前面ウィンドウをゲーム画面の上に描画できません。

## 使い方

1. ゲームのレーンがあるモニターを選び、「カバー幅」をレーンに合わせます。カバー本体を左右にドラッグして位置を合わせられます。「左位置」欄でも調整できます。
2. 「判定ライン Y」に画面上端から判定ラインまでのピクセル数を設定します。「ノーツ出現位置 Y」も同様に設定します。
3. ゲーム内のハイスピードを「DJMAX ハイスピード」に入力します。
4. カバー下辺を上下にドラッグするか「カバー下辺の高さ」を変更します。
5. カバーで隠れた部分を見たいときは、カバーを右クリックしてください。不透明度が 100% と 20% で交互に切り替わります。20% の状態でもカバーの右クリックやドラッグができます。設定画面はタスクバーに残り、必要に応じて最小化できます。

## 緑数字の校正

初期値の「1.0x 全長落下時間 = 2693 ms」は、[韓国のプレイヤーによる FHD での実測と公開計算式](https://github.com/johypark97/ez2djmax-speed-calculator/blob/main/app/core/calculator.ts)を採用した値です。120 BPM の 1 小節（2 秒）が 560 px、レーン高が 754 px なので `754 ÷ 560 × 2000 ≈ 2693 ms` です。これはゲーム公式の換算値ではなく、スキンや表示設定が異なる場合は校正してください。例えばハイスピ 5.0 で出現位置から判定ラインまで 400 ms なら、`400 × 5 = 2000 ms` と入力します。録画をコマ送りにして測ると調整しやすくなります。

計算式：`緑数字 = 0.6 × (1.0x 全長落下時間 ms ÷ ハイスピ) × (判定ライン Y − カバー下辺 Y) ÷ (判定ライン Y − ノーツ出現位置 Y)`。緑数字は IIDX の 60 fps 基準で表示時間を表し、600 が 1 秒に相当します。表示値は四捨五入します。DJMAX の特殊な速度変化エフェクトには対応していません。

## ショートカット

| キー | 動作 |
| --- | --- |
| Ctrl+Alt+F7 | 設定画面を前面に出す |
| Ctrl+Alt+F8 | カバーを表示／非表示 |
| Ctrl+Alt+↑ / ↓ | カバー高さを 5 px 調整 |
| Ctrl+Alt+← / → | ハイスピードを 0.1 調整 |

終了するときはタスクバーから設定画面を開き、右上の × を押してください。Ctrl+Alt+F7 でも設定画面を前面に出せます。設定は `%APPDATA%\DjmaxSuddenPlus\settings.ini` に保存されます。ショートカットがほかのアプリと重なる場合は登録されない可能性があります。

## 再ビルド

ソースを変更した場合は `build.cmd` を実行してください。Windows の .NET Framework C# コンパイラを使用します。管理者権限は不要です。
